# MusicPilot v2.0 开发路线图

**目标**：完全对齐 MoviePilot 能力

---

## 优先级定义

- **P0**：核心功能，必须完成
- **P1**：重要功能，建议完成
- **P2**：增强功能，可选完成

---

## P0 任务

### 1. qBittorrent 下载器完整实现

**当前状态**：基础实现（288 行）  
**目标状态**：完整实现（对齐 MoviePilot）

**待开发功能**：

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 种子文件上传 | 支持上传 .torrent 文件，不仅限于 URL | 高 |
| 标签管理 | 给种子打标签，识别 MusicPilot 任务 | 高 |
| 分类支持 | 支持下载分类 | 中 |
| 集数/曲目选择 | 选择性下载特定文件 | 中 |
| 下载器信息 | 上传/下载速度统计 | 中 |
| 已完成未整理列表 | 获取已完成但未整理的种子 | 高 |
| 转移完成处理 | 整理完成后打标签 | 高 |
| 获取种子文件列表 | 获取种子内文件列表 | 中 |
| 定时重连 | 自动重连机制 | 中 |

**参考实现**：MoviePilot `app/modules/qbittorrent/__init__.py`

---

### 2. 音乐 PT 站点支持

**目标**：至少支持 2 个音乐 PT 站点

**待调研站点**：
- [ ] JPS (JPopSuki)
- [ ] Redacted
- [ ] Orpheus
- [ ] 其他音乐 PT

**需要实现**：
- 站点认证
- 搜索接口
- RSS 订阅
- 种子下载

---

### 3. Telegram 消息推送

**目标**：实现 Telegram Bot 推送

**需要实现**：
- Bot 配置
- 消息推送
- 交互按钮（可选）
- 命令处理（可选）

---

## P1 任务

### 4. 订阅自动下载逻辑完善

**需要完善**：

### 5. 前端重写

**目标**：对齐 MoviePilot 前端体验

**需要实现**：
- 仪表盘

- 订阅管理

- 日志查看
