# MusicPilot v2.0

> 基于 v1 架构的音乐库管理二期扩展

## 📋 概述

MusicPilot v2.0 是项目的二期开发版本，在 v1 核心功能（扫描、刮削、播放）基础上，新增三大功能模块：
- **Chart Module**: 音乐榜单与排行榜
- **Organize Module**: 智能音乐整理与分类
- **MediaServer Module**: DLNA/Chromecast 媒体服务器

## 🎯 目标

1. 提供音乐榜单聚合与追踪功能
2. 实现智能音乐整理与自动分类
3. 支持多设备 DLNA/Chromecast 串流播放
4. 保持与 v1 的向后兼容

## ✨ 功能清单

### Chart Module
- [ ] 主流音乐榜单聚合（Billboard, UK Charts, QQ音乐等）
- [ ] 榜单历史数据追踪
- [ ] 新歌发布提醒
- [ ] 榜单趋势可视化

### Organize Module
- [ ] 智能文件夹整理规则
- [ ] 自动重命名与归类
- [ ] 封面/歌词批量处理
- [ ] 重复文件检测与清理

### MediaServer Module
- [ ] DLNA/UPnP 服务端
- [ ] Chromecast 支持
- [ ] 多设备同时播放控制
- [ ] 转码与质量控制
