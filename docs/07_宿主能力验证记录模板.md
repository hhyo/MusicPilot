# 07. 宿主能力验证记录模板

> 用途：供后续人工联调或宿主接入阶段记录探针验证结果。  
> 注意：本模板本身不代表已经通过验证；所有结论必须基于真实宿主联调结果填写。

- 插件版本：
- 验证人：
- 环境说明：
- 关联分支 / 提交：

## 7.2 记录规则

- 每个探针项至少记录一次真实请求与响应摘要。
- 若失败，必须记录失败现象、日志位置和初步判断。
- 若部分通过，需明确哪些字段已确认、哪些字段仍待验证。
- 每条记录建议同时标注：
  - `source_code_verified`：是否已对照宿主源码确认接口路径、方法、参数与鉴权方式
  - `runtime_verified`：是否已在真实宿主上拿到实际请求/响应样例
  - `verification_state`：`verified / unverified / placeholder`
- 建议附上请求样例、响应样例和截图或日志引用位置。
