# 05. 宿主能力探针验证清单

> 目标：在让 Codex 大规模实现业务前，先验证 MoviePilot 宿主可复用能力的真实接口、调用方式和返回结构。  
> 输出物：每一项探针都要留下验证记录、示例请求、示例响应、失败日志与结论。

## 5.1 验证原则
- 先验证“能不能接”，再开始大量写业务代码
- 只验证 MVP 必需能力
- 所有探针都要可复现、可记录、可归档

## 5.2 探针项总览

| 编号 | 能力项 | 目标 | 通过标准 |
|---|---|---|---|
| P01 | 插件入口注册 | 验证独立 MusicPilot 入口可挂载 | 宿主界面出现入口且可跳转占位页 |
| P02 | 前端远程组件加载 | 验证插件前端静态资源可被宿主加载 | 占位页面正常渲染，无白屏 |
| P03 | 插件 API 注册 | 验证 `/api/v1/plugin/musicpilot/*` 可用 | `GET /health` 返回 200 |
| P04 | 宿主站点配置读取 | 验证插件能读取已启用 PT 站点列表 | 返回站点基础信息且不泄露敏感字段 |
| P05 | 宿主 PT 搜索底座 | 验证插件可调用 PT 搜索并拿到结果 | 用测试关键词得到非空结果结构 |
| P06 | 搜索结果结构识别 | 验证 title/size/seeders 等字段可解析 | 至少 1 个站点解析成功 |
| P07 | 下载器列表读取 | 验证插件可获取默认下载器与可用下载器列表 | 返回下载器 id/name/status |
| P08 | 下载派发 | 验证插件能创建下载任务 | 返回 downloader_task_id |
| P09 | 下载状态回调/轮询 | 验证插件可感知下载中/完成/失败 | 至少一条任务状态变化被记录 |
| P10 | 通知能力 | 验证插件可复用宿主通知 | 发送一条测试通知成功 |
| P11 | 定时任务 service | 验证插件定时 service 可运行 | service 被触发并产生日志 |
| P12 | 配置持久化 | 验证插件配置可读写 | 保存 profile 后可再次读取 |

## 5.3 建议的最小探针接口
```text
GET  /api/v1/plugin/musicpilot/health
GET  /api/v1/plugin/musicpilot/probe/sites
POST /api/v1/plugin/musicpilot/probe/search
GET  /api/v1/plugin/musicpilot/probe/downloaders
POST /api/v1/plugin/musicpilot/probe/dispatch
POST /api/v1/plugin/musicpilot/probe/notify
POST /api/v1/plugin/musicpilot/probe/config
```

## 5.5 建议执行顺序
1. 入口与前端加载
2. API 健康检查
3. 配置读写
4. 站点读取
5. PT 搜索
6. 下载器与下载派发
7. 通知
8. 定时任务

## 5.6 决策门槛
只有当以下 4 项都通过后，Codex 才进入业务主线开发：
- P03 插件 API 注册
- P05 宿主 PT 搜索底座
- P08 下载派发
- P11 定时任务 service
