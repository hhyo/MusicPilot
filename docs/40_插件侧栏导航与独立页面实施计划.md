# 插件侧栏导航与独立页面实施计划

## 目标

让 MusicPilot 适配 MoviePilot `v2.9.27` 的插件侧栏导航与独立页面能力。

## 范围

### MusicPilot 仓库

- 新增插件侧栏导航声明
- 新增 `AppPage` 远程组件
- 更新联邦暴露与运行时打包
- 补单测与语义测试
- 更新 README 与运行态验证文档

### 本地宿主验证环境

- 最小升级本地 `MoviePilot` / `MoviePilot-Frontend` 到支持：
  - `plugin/sidebar_nav`
  - `/plugin-app/:pluginId/:navKey?`
  - `AppPage` 联邦加载

> 仅用于本地运行态验证，不改变 MusicPilot 项目对宿主接口的正式声明范围。
