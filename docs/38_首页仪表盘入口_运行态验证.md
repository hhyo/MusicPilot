# 38. 首页仪表盘入口运行态验证

## 目标

验证 MusicPilot 是否已经通过 MoviePilot 首页 dashboard 提供更浅的访问入口，并确保点击后能继续复用已完成的插件详情页远程组件入口。

## 本轮实现

- 插件入口新增：
  - `get_dashboard_meta()`
  - `get_dashboard()`
- 前端远程组件新增：
  - `Dashboard.vue`
- federation 暴露新增：
  - `./Dashboard`
- 交互方式：
  - 首页 dashboard 卡片点击“打开 MusicPilot”
  - 跳转到 `/#/plugins?id=musicpilot`
  - 由宿主插件页自动打开 MusicPilot 详情弹窗

## 关键运行态结论

### 1. dashboard 契约已进入宿主

真实宿主接口验证：

- `GET /api/v1/plugin/dashboard/meta`
  - 返回：`[{"id":"musicpilot","name":"MusicPilot","key":"home"}]`
- `GET /api/v1/plugin/dashboard/musicpilot/home`
  - 返回：
    - `render_mode=vue`
    - `cols={"cols":12,"md":6,"lg":4}`
    - `attrs.title=MusicPilot`
    - `attrs.subtitle=音乐发现、元数据与整理工作台`

### 2. 首页卡片可正常渲染

在本地宿主 `http://127.0.0.1:5173/#/dashboard` 的真实页面中：

- 宿主已拉取 `musicpilot` 的 dashboard 元信息
- 远程 `Dashboard` 组件已成功加载
- 首页可见轻量摘要卡片：
  - `Metadata`
  - `Discovery`
  - `Workspace`
- 卡片视觉上保持宿主 dashboard 卡片风格，不内嵌完整 MusicPilot 页面

### 3. 点击后能打开插件详情页

真实点击首页卡片按钮“打开 MusicPilot”后：

- 路由切换为：
  - `/#/plugins?id=musicpilot`
- 宿主插件页自动打开 `MusicPilot` 详情弹窗
- 详情弹窗继续加载现有远程 `Page` 组件

## 一个需要明确保留的边界

首页 dashboard 是否显示 MusicPilot 卡片，仍然受宿主 `Dashboard` 启用配置控制。

也就是说：

- 插件已经正确提供 dashboard 能力
- 宿主能够正确拉取并渲染它
- 但如果宿主当前 `MP_DASHBOARD` / 用户 dashboard 配置里没有启用 `musicpilot:home`
  - 首页默认不会直接展示这个卡片

本轮真实验证时，我在宿主页面配置中启用了 `musicpilot:home`，随后卡片正常出现并可点击进入插件详情页。
