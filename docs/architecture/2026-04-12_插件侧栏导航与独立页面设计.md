# 插件侧栏导航与独立页面设计

## 背景

MoviePilot `v2.9.27` 为插件增加了新的全页入口能力，不再只依赖：

- 插件中心详情弹窗 `get_page()`
- 首页仪表盘 `get_dashboard()`

新增能力的核心是：

- 后端聚合插件声明的 `get_sidebar_nav()`
- 前端新增 `/plugin-app/:pluginId/:navKey?` 独立路由
- 联邦组件新增全页组件约定：
  - `AppPage{Pascal}`
  - `AppPage`
  - 回退到 `Page`

MusicPilot 目前已经支持：

- `Page`
- `Dashboard`
- 插件中心详情弹窗
- 首页仪表盘入口

但还没有：

- `get_sidebar_nav()`
- `AppPage`
- 侧栏导航独立页面入口

## 原理梳理

`v2.9.27` 的关键上游变更有两处：

### 1. MoviePilot 后端

- 新增 `PluginSidebarNavItem`
- 新增 `GET /api/v1/plugin/sidebar_nav`
- `PluginManager.get_plugin_sidebar_nav()` 会聚合：
  - 已启用插件
  - `render_mode = vue`
  - 实现了 `get_sidebar_nav()`

每个侧栏项包含：

- `plugin_id`
- `nav_key`
- `title`
- `icon`
- `section`
- `permission`
- `order`

### 2. MoviePilot 前端

- 新增独立路由：
  - `/plugin-app/:pluginId/:navKey?`
- 新增壳页：
  - `plugin-app.vue`
- 联邦加载顺序：
  - `AppPage{Pascal(nav_key)}`
  - `AppPage`
  - `Page`
- `DefaultLayout` / `appcenter` 会把 `plugin/sidebar_nav` 聚合进主侧栏与应用中心

## MusicPilot 接入目标

本轮只把 MusicPilot 补齐为 `v2.9.27` 兼容插件：

1. 插件声明一个侧栏导航入口
2. 插件提供 `AppPage` 远程组件
3. 插件在独立页面中加载现有 MusicPilot 工作台
4. 保持现有：
   - `Page`
   - `Dashboard`
   - 插件中心详情弹窗
   - 首页仪表盘

## 设计边界

### 本轮要做

- 插件入口新增 `get_sidebar_nav()`
- 前端联邦暴露新增 `./AppPage`
- 新增 `frontend/src/plugin/AppPage.vue`
- 让 `AppPage` 以“全页模式”挂载现有 MusicPilot 前端工作台
- 支持单一主入口 `nav_key = main`
- 本地宿主环境按官方提交最小升级到支持该契约，用于真实验证

### 本轮不做

- 不一次性实现多个 `nav_key`
- 不实现 `AppPageSettings` / `AppPageCharts` 等多页面远程组件
- 不改 MusicPilot 自己的页面信息架构
- 不改现有插件中心详情弹窗语义
- 不重做首页仪表盘

## 侧栏导航项设计

MusicPilot 第一轮只声明一个主入口：

- `nav_key`: `main`
- `title`: `MusicPilot`
- `icon`: `mdi-music-note-outline`
- `section`: `discovery`
- `permission`: `discovery`
- `order`: `90`

原因：

- 当前最成熟的入口能力集中在 `charts / search / metadata`
- 放在 `discovery` 分组最贴近用户心智
- 仍然保留插件中心和首页入口，不造成路径冲突

## AppPage 组件设计

`AppPage.vue` 与当前 `Page.vue` 的差异：

- `Page.vue`
  - 面向插件中心详情弹窗
  - 自带“关闭 / 插件设置”头部操作
- `AppPage.vue`
  - 面向宿主独立页面
  - 不显示弹窗语义按钮
  - 直接作为独立工作台壳页

实现方式：

- 继续复用 `mountMusicPilotApp(...)`
- 默认使用 `memory` history
- 为后续多 `nav_key` 预留一个轻量初始路由映射
  - 当前 `main -> /`

## 运行态验证策略

当前本地宿主参考源码是 `v2.9.25`，不包含：

- `plugin/sidebar_nav`
- `/plugin-app/:pluginId/:navKey?`
- `AppPage` 联邦加载逻辑

因此本轮真实验证需要：

1. 先在 MusicPilot 实现插件侧兼容
2. 再将本地 MoviePilot / MoviePilot-Frontend 最小升级到对应官方提交
3. 最后在本地宿主环境验证：
   - 侧栏出现 `MusicPilot`
   - 点击后进入独立页面
   - 页面能正常加载 MusicPilot 工作台
